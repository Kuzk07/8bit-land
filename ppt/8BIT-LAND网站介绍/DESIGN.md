# 8BIT★LAND 网站介绍 · 视觉设计稿

> 通用设计原则路线（未命中学术 / 咨询 / 政务三类预设风格），全部常量由本项目自定。

## 1. 画布与母版

画布 **1280 × 720**，`box-sizing: border-box`。

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| A · 标题块 | 0–120px | 120（含上留白 28） | 页面主标题 **36px**，左侧 x=64 起排；右侧可放一枚 24px 的英文小标（如 `MODULE 01`） |
| B · 内容区 | 120–660px | 540 | 正文、卡片、截图；**禁止挤占 A / C** |
| C · 页脚条 | 660–720px | 60（含下留白 20） | 左：`★ 8BIT LAND` 14px 弱化字；右：`NN / 08` 14px |
| 页面 padding | 上 28 / 下 20 / 左右 64 | — | 所有内容在此安全区内 |

封面、结束页省略 C 区，采用自定义版式；02–07 六页严格复用母版。

## 2. 色彩池（4 个 hex）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 主色 · 深空紫 | `#14101F` | 全篇背景、大色块、压暗蒙版 |
| 中性 · 雾白紫 | `#F2E9FF` | 标题、正文、页码（弱化时用 rgba 0.45 / 0.28） |
| 辅色 · 薄荷青 | `#93DCE4` | 数据、结构线、次要强调、SVG 描边 |
| 强调 · 糖果粉 | `#E79EC4` | 每页只给一个焦点：巨型数字、模块编号、关键按钮隐喻 |

面积分配（每页单独声明，见 §6 映射表）：

| 色彩角色 | 常规页占比 | Hero 页占比 |
| :--- | :--- | :--- |
| 主色 | 55–62% | 60–70% |
| 辅色 | 18–24% | 10–15% |
| 强调 | ≤ 8% | 12–18% |
| 中性 | 其余 | 其余 |

### 渐变与半透明

- 强调渐变（全篇统一）：`linear-gradient(135deg, #93DCE4 0%, #E79EC4 100%)`，只用于**条形装饰、巨型数字下层光晕**，不铺大面积。
- 卡片：`background: rgba(242,233,255,0.05)`，`border: 1px solid rgba(242,233,255,0.14)`，直角（`borderRadius: 0`）——像素风不做圆角。
- 截图浮起：`boxShadow: '8px 8px 0 rgba(20,16,31,0.85), 0 0 0 2px rgba(242,233,255,0.18)'`，硬投影，不用彩色模糊阴影。
- 背景网格：全篇在 `zIndex:0` 铺一层 40×40 像素的 rgba(242,233,255,0.03) 点阵（用 1px 线 + 39px 间隔的 Box 阵列或 SVG pattern），呼应网站的点阵质感。

## 3. 字体系统

两套家族：标题系 **mplus_hzk_12**（本站点内联的中文点阵字体，Windows 已安装，本机可直接渲染），正文系 **Microsoft YaHei**。

| 层级 | 字号 / 行高 | 字重 | 字距 | 家族 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 96 / 96 | 400 | 6 | mplus_hzk_12 | 仅封面 |
| 巨型数字 | 120 / 120 | 400 | 2 | mplus_hzk_12 | 06 页锚点 |
| 页面主标题 | 36 / 48 | 400 | 2 | mplus_hzk_12 | A 区，全篇一致 |
| 卡片小标题 | 24 / 36 | 400 | 1 | mplus_hzk_12 | 卡片头、模块编号 |
| 正文 | 21 / 34 | 400 | 0 | Microsoft YaHei | 段落 |
| 辅助说明 | 17 / 28 | 400 | 0 | Microsoft YaHei | 图注、参数注释 |
| 页脚 / 页码 | 14 / 20 | 400 | 1 | mplus_hzk_12 | C 区 |

**硬约束**：像素字体的字号必须是 **12 的整数倍**（12 / 24 / 36 / 48 / 96 / 120），否则点阵被插值缩放会长出灰边——这正是本项目最在意的细节。正文换成雅黑后不受此限。

## 7. 自检（每页提交前）

1. A 区标题位置、字号全篇一致；
2. 本页强调色只出现在一个焦点元素上，且面积 ≤ 8%（Hero 页 ≤ 18%）；
3. 与上一页版式不同、视觉重量不同（最大元素面积比 > 1.5:1 或结构明显不同）；
4. 有 ≥ 1 个视觉锚点（≥ 44px 的元素或占 B 区 ≥ 40% 的图）；
5. 总高度 ≤ 720，无溢出；页脚页码 `NN / 08` 存在（除封面、结束页）；
6. 只用本文件的 4 个 hex 与 2 套字体。
